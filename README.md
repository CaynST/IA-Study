# Paquete de fuentes para construir un sitio de estudio de IA

Archivos:
- `PROMPT-OPENCODE.md`: instrucciones completas para el agente de programación.
- `GUIA-CONTENIDO.md`: mapa pedagógico de los cuatro módulos y sus secciones.
- `BANCO-PREGUNTAS.md`: preguntas semilla para ampliar y validar.
- `tema-1.1.md`, `tema-1.2.md`, `tema-1.3.md`, `tema-1.5.md`: texto extraído de los 198 folios de los cuatro PDFs originales, con encabezados por página para trazabilidad.

**Importante:** los cuatro archivos `tema-*.md` son **transcripciones de texto extraído**, no resúmenes editados ni lecciones terminadas. La extracción puede alterar tablas, columnas, fórmulas o diagramas; revisar los PDFs originales para esos casos. El sitio debe transformar el contenido en explicaciones propias, no copiar las diapositivas enteras. Las fuentes fueron aportadas por el usuario; verificar los derechos de publicación antes de redistribuir texto íntegro o las diapositivas.

Uso: descomprime el ZIP en una carpeta de tu proyecto y pega el contenido de `PROMPT-OPENCODE.md` en OpenCode. Conserva los cuatro PDF originales como referencia opcional para ver diagramas, tablas y figuras.
